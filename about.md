# Auto Deco

Bikin layout di level editor, tekan tombol **Deco** di samping tombol trash,
pilih tema + mood, lalu deco otomatis ditempel ke layout kamu.

- Tema: Space, Slaughter, Neon, Forest, Cyber
- Mood: Clean, Slaughterhouse, Limbo, Dreamy
- Beat sync: deco besar dan aksen ikut ketukan (BPM + kecepatan)
- Palette bisa kamu ambil dari objek deco yang kamu select sendiri
